# 分岐型小説シナリオ：実績解除の音がする。

**版**: v1.0（ゲーム実装反映）

---

## 0. この物語の法則（構成の芯）

**ゲームの「実績解除」のような音が、人生の節目に聞こえる。他人の解除に立ち会い続ける主人公は、自分自身の音を探していく。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **他人の相談にどう向き合うか** | 話を聞く／断る | 他者への関心と自己の余裕 |
| 第2分岐 | **後輩の決断をどう受け止めるか** | 背中を押す／慎重にさせる | 応援と忠告のバランス |
| 第3分岐 | **自分の役割をどう捉えるか** | 告白／沈黙 | 自己開示と自己防衛 |
| 第4分岐 | **他者の言葉をどう受け止めるか** | 受容／反論 | 素直さと頑固さ |
| 第5分岐 | **最後にどう感じるか** | 祝福／挑戦／羨望／（隠）気づき | 人生観の選択 |

**走るモチーフ**（各シーンに散らす）:
- **実績解除の音（ポロン）**: 人生が一段階進む瞬間の比喩
- **立会人**: 他人の節目に居合わせる役割
- **トロフィー**: 人生の達成を可視化するイメージ

**語り口**: 一人称。32歳の独身サラリーマン視点。内省的だが、ユーモアも交える。ゲーム用語を自然に使う。

## 1. 作品概要（100字以内）

**フック**: 新婚の同僚が「うちの妻が」と言った瞬間、ゲームの実績解除の音がした気がした。結婚、昇進、婚約——誰かの人生が一段階進む瞬間に、いつも居合わせる「立会人」の物語。

**選択の意味**: 他者の節目をどう受け止め、自分の人生をどう捉えるか。立会人としての自分を受け入れるか、自らも解除する側に回るか。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] 話を聞く → S03-A ─┬─（分岐②）
      │                        ├─ [A] 背中を押す → S04-A ─┐
      │                        └─ [B] 慎重に考えろ → S04-B ─┤
      └─ [B] 断る → S03-B ──────────────────────────────────┘
         │
S05（合流・分岐③）← S03-B / S04-A / S04-B
   ├─ [A] 実績解除の話をする → S06-A ─┐
   └─ [B] 話を変える → S06-B ─────────┘
         │
S07（合流・分岐④）← S06-A / S06-B
   ├─ [A] 受け入れる → S08-A ─┐
   └─ [B] 納得できない → S08-B ─┘
         │
S09（合流・分岐⑤）← S08-A / S08-B
   ├─ [A] 心から祝福する → E01（Good）
   ├─ [B] 自分も始めようと思う → E02（Normal）
   ├─ [C] 羨ましさが勝つ → E03（Bad）
   └─ [隠・全ED回収] 気づいたことがある → E04（Secret）
```

### 隠しルート（Secret: E04）

**解放条件**: E01・E02・E03 をすべて回収済み

1. 上記条件を満たした状態で S09 に「気づいたことがある」が出現
2. 立会人の**本当の意味**に気づく第四の道

## 5. エンディング一覧

| ID | 種類 | タイトル | 感情 | キャッチコピー |
|----|------|----------|------|----------------|
| E01 | Good | 祝福の音 | 温かさ・受容 | 誰かの実績を見届けることも、立派な役割だった |
| E02 | Normal | 新しい音 | 希望・決意 | 見届ける側から、解除する側へ |
| E03 | Bad | 遠い音 | 寂しさ・羨望 | 実績解除の音は、いつも他人から聞こえる |
| E04 | Secret | 連鎖する音 | 気づき・感動 | 実績解除は、誰かの立会いがあって初めて鳴る |

### E01 Good「祝福の音」

立会人としての自分を受け入れ、他者の幸せを心から祝福できるようになった。自分自身にも「誰かの幸せを心から祝えた」という実績が解除される。

### E02 Normal「新しい音」

他者を祝福しつつも、自分自身も「解除する側」になろうと決意する。連絡していなかった誰かにスマホで連絡しようとする。

### E03 Bad「遠い音」

他者の実績解除を祝福できず、羨望と焦りに囚われたまま。何も変わらない日常に戻る。

### E04 Secret「連鎖する音」

全エンディング回収後。立会人がいるから実績が解除される——自分は単なる観察者ではなく、他者の実績解除の**触媒**だったと気づく。

## 6. 執筆メモ

**主要ロケーション**
- 給湯室の前（自販機）
- 会議室
- 居酒屋
- オフィスの廊下

**共通描写（再利用可）**
1. 実績解除の音「ポロン」の描写
2. トロフィーが光るイメージ
3. 「おめでとう」と言う瞬間

**執筆上の注意**
- 実績解除の比喩は、ゲーマーでなくても共感できる書き方に
- 主人公の内省は深刻になりすぎない。軽いユーモアを交える
- 林の言葉「立会人も才能」が物語の核。押し付けがましくならないよう
- Goodエンドは**自己受容**、Secretエンドは**気づき**の違いを明確に

**編集チーム向け1行サマリー**: 人生の節目に「実績解除の音」が聞こえる主人公が、立会人としての自分を受け入れるか、自ら解除する側に回るかを選ぶ日常ヒューマンドラマ。
