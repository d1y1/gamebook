# 分岐型小説シナリオ：反AI組織アニミスト 第11話「残響」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第11話。真エンドは第12話「名を残す」（最終回）へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 閉じた駅に入るか | 公共空間の記憶 |
| 第2分岐 | ホームで何を触るか | 最後の触媒選択 |
| 第3分岐 | 楓・老木・灰野、誰と共にか | 継承のネットワーク |
| 第4分岐 | 残響を残すか、消すか | 記憶の公開

**走るモチーフ**: 廃止された地上駅／第3話の触媒と同線／「終電の向こう側」との交差可能／ホームの残響

---

## 1. 作品概要

**フック**: 「第11回：残響。閉じた駅へ」。完全自動化で不要になったホームに、百本の時計の針が向かう——零時三十分。ここが、すべての触媒を結ぶ地点だった。

**選択の意味**: 残響とは、消えなかった音の記憶。最後の触れ直しを行った者だけが、第12話の名付けへ進む。

---

## 2. 分岐マップ

```
START → S01（閉じた駅・夜）
  ├─ ホームへ → S03
  ├─ 老木の型を持参 → S02 → S03
  └─ セラに位置を送らない → E04

S03（残響のホーム）
  ├─ 柱時計に触れる → S04
  ├─ ホームに名を付ける → S04-NAME
  └─ 音だけを聴く → E03

S04（触媒の統合）
  ├─ 残響を残す → E05（True）→ 第12話
  ├─ 残響を封じる → E02
  └─ [隠] セラに聴かせる → E06
```
