# 分岐型小説シナリオ：反AI組織アニミスト 第2話「証人名簿」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第2話。真エンディングは第3話「触媒」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 入るか、灰野に聞くか、欠席か | 組織への距離感 |
| 第2分岐 | 一緒に読むか、独りか、逃げるか | 共闘と孤独 |
| 第3分岐 | 証人を選ぶか、自分か、選ばないか | 他者と物のあいだ |
| 第4分岐 | 第3回を受けるか、閉じるか | 儀式への参加 |

**走るモチーフ**: 証人候補／記号の進行（呼び→触れる→名付ける→守る→渡す→残す）／灰野の「済」の隣の空白

---

## 1. 作品概要

**フック**: 「第2回：証人名簿の続きから」。同じ時計店跡で、触媒候補の名前が並び、朱色の糸が書き換えられていく。あなたの一行の下に、見知らぬ誰かの名が——先に書かれている。

**選択の意味**: 続きを読む者は、一人の「証人」を選ばされる。選んだ側だけが、第3話へ進む。

## 3. 分岐マップ

```
START → S01（再び零時三十分）
  ├─ 入る → S03
  ├─ 灰野に聞く → S02 → S03
  └─ 帰る → E03

S03（名簿の続き）
  ├─ 楓と一緒に読む → S04 → 楓/自分/時計 → E02 / S05 / E04
  ├─ 独りで読む → S04-ALONE → S05
  └─ 出る → E01

S05（触媒の予告）
  ├─ 第3回を受ける → E05（True）→ 第3話
  ├─ 名簿を閉じる → S05-CLOSE → E04
  └─ [隠] 空白行を探す → S05-GAP → E06 / E05
```

---

## 4. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 逃げた続き | 読まずに逃げても、糸は結ばれる |
| E02 | Bad | 差し出した | 楓を選んだつもりが、選ばせていた |
| E03 | Normal | 第2回欠席 | 欠席しても、名は消えない |
| E04 | Good | 保留 | 選ばなければ、触媒は来ない |
| E05 | True | 触媒へ | 名簿の続きは、街に触れる話になる → 第3話 |
| E06 | Secret | 空白に書いた | 済の隣に書く者は、もう証人ではない |

---

## 5. シリーズ位置

- 前話: 第1話「呼び声」True「応えた」
- 次話: 第3話「触媒」（True接続）
- 裏: Secretは物側への転落ルートの起点
