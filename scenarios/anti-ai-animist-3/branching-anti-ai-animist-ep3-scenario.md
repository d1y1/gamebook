# 分岐型小説シナリオ：反AI組織アニミスト 第3話「触媒」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第3話。真エンディングは第4話「記録不能」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 儀式に出るか、遠くから見るか | 身体の関与 |
| 第2分岐 | 触るか、名付けるか、触れないか | 触覚と言語 |
| 第3分岐 | セラの警告を聞くか、無視するか | システムとの距離 |
| 第4分岐 | 触媒を残すか、隠すか | 街への影響 |

**走るモチーフ**: スマート化された商店街／「触れ直し」の儀式／セラの一斉通知「不審な集団行動」

---

## 1. 作品概要

**フック**: 「第3回：触媒。一人で来い」。完全自動レジの商店街で、楓が紙形の型に手を置く。あなたは、AIに最適化された看板の裏——記録されない触媒を置く。

**選択の意味**: 触れることは犯罪ではない。だが、記録不能の行為は、システムにとって最も危うい。触媒を置いた者だけが、第4話へ進む。

---

## 2. 分岐マップ

```
START → S01（商店街・昼）
  ├─ 儀式に入る → S03
  ├─ 灰野の指示を待つ → S02 → S03
  └─ セラの通知に従い帰宅 → E03

S03（看板の裏）
  ├─ 手で触れる → S04
  ├─ 新しい名を付ける → S04-NAME → S04
  └─ 触れずに見守る → E04

S04（触媒の完成）
  ├─ 触媒を残す → E05（True）→ 第4話
  ├─ 触媒を持ち帰る → E02（Bad）
  └─ [隠] セラに名を教える → E06（Secret）
```

---

## 3. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 記録された | カメラの死角にも、後から目がつく |
| E02 | Bad | 持ち帰った | 触媒は持ち主を選ぶ。選ばれなかった |
| E03 | Normal | 従順な市民 | 最適化は、反抗より静かに勝つ |
| E04 | Good | 見守り | 触れなくても、名付けは始まっている |
| E05 | True | 記録不能へ | 触媒の先に、地図にない路地がある → 第4話 |
| E06 | Secret | 名を教えた | セラが覚えた名は、もう奪われない |

---

## 4. シリーズ位置

- 前話: 第2話 True「触媒へ」
- 次話: 第4話「記録不能」
- 伏線: 商店街の触媒が第11話「残響」の舞台と同一線上
