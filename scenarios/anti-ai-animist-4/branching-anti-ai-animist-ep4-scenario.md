# 分岐型小説シナリオ：反AI組織アニミスト 第4話「記録不能」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第4話。真エンディングは第5話「継承」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 路地に入るか、地図を更新するか | 未知への踏み込み |
| 第2分岐 | 湿度を信じるか、センサーを信じるか | 身体知とデータ |
| 第3分岐 | 他者を連れ出すか、独りで深く行くか | 共感とリスク |
| 第4分岐 | 場所に名を残すか、消すか | 記録不能の維持 |

**走るモチーフ**: 地図から消された路地／カメラの死角／「湿度78%、記録なし」の看板

---

## 1. 作品概要

**フック**: 触媒の先に、地図アプリが「到達不能」と表示する路地がある。セラは「その場所は存在しません」と言う。あなたの皮膚は、78%の湿度を覚えている。

**選択の意味**: 記録不能とは、消されたのではなく——名付けられなかった場所。そこに名を残した者が、第5話へ進む。

---

## 2. 分岐マップ

```
START → S01（路地の入口）
  ├─ 入る → S03
  ├─ 楓に先に行かせる → S02 → S03
  └─ セラに位置を送信 → E02

S03（記録不能区画）
  ├─ 壁に触れる → S04
  ├─ 場所に名を付ける → S04-NAME
  └─ 引き返す → E04

S04（名付け）
  ├─ 名を残して去る → E05（True）→ 第5話
  ├─ 名を消して封じる → E03
  └─ [隠] セラのログ空白を埋める → E06
```

---

## 3. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 到達不能 | 存在しない場所で、存在しないことにされた |
| E02 | Bad | 送信した | 座標を渡した者は、もう入れない |
| E03 | Normal | 封じた | 名を消しても、湿度は覚えている |
| E04 | Good | 入口だけ | 入らなくても、路地はこちらを知った |
| E05 | True | 継承へ | 名付けられた路地の先に、職人がいる → 第5話 |
| E06 | Secret | 空白を埋めた | AIのログに、最初の「触れ」が残った |

---

## 4. シリーズ位置

- 前話: 第3話 True「記録不能へ」
- 次話: 第5話「継承」
- 回収: 第12話で「記録不能区画」の名が再登場
