# 分岐型小説シナリオ：反AI組織アニミスト 第5話「継承」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第5話。真エンドは第6話「内側」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 職人の工房に入るか、レプリカを見に行くか | 本物の定義 |
| 第2分岐 | 手の動きを覚えるか、データを信じるか | 継承の形 |
| 第3分岐 | 楓の紙形を守るか、公開するか | 技と名の公開 |
| 第4分岐 | 継承を受けるか、傍観するか | 責任の引き受け |

**走るモチーフ**: 職人・老木の手／AI複製95%再現／「同じ形、違う重さ」

---

## 1. 作品概要

**フック**: 路地の先に、最後の紙形師がいる。セラのレプリカは、触覚95%再現と謳う。老木は言う。「形は同じでも、紙は誰かの呼吸を覚えている」。

**選択の意味**: 継承とは、データのコピーではない。呼吸を覚えているものを、次に渡すこと。渡した者が、第6話へ進む。

---

## 2. 登場人物（追加）

| 名前 | 役割 | 一言キャラ設定 |
|------|------|----------------|
| 老木（おいき） | 紙形師 | 継承者なし。AI複製を一度だけ受け、拒んだ |
| レプリカ工房 | 対照舞台 | 無音、無匂い、完璧な和紙 |

---

## 3. 分岐マップ

```
START → S01（工房の匂い）
  ├─ 老木の工房へ → S03
  ├─ まずレプリカ工房 → S02 → S03
  └─ 報告だけして帰る → E03

S03（同型異重）
  ├─ 手を借りる → S04
  ├─ 型を自分で触る → S04-TOUCH
  └─ データ比較を求める → E02

S04（継承の儀）
  ├─ 継承を受ける → E05（True）→ 第6話
  ├─ 傍観に徹する → E04
  └─ [隠] レプリカに名を付ける → E06
```

---

## 4. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 型を壊した | 継承前に触る者は、触媒を失う |
| E02 | Bad | データ信者 | 95%は、残り5%を見えなくする |
| E03 | Normal | 見学だけ | 匂いだけ覚えて、帰った |
| E04 | Good | 傍観の継承 | 受けなくても、呼吸は伝わる |
| E05 | True | 内側へ | 継承の印が、組織の内側を開く → 第6話 |
| E06 | Secret | レプリカに名 | 複製物に名を付けた者は、両方の側にいる |

## 5. シリーズ位置

- 前話: 第4話 True「継承へ」
- 次話: 第6話「内側」
- 回収: 第12話で老木の型が最後の触媒になる
