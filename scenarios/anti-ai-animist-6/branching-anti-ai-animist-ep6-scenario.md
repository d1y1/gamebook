# 分岐型小説シナリオ：反AI組織アニミスト 第6話「内側」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第6話。真エンドは第7話「供物」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 疑心を口にするか、黙るか | 組織内の信頼 |
| 第2分岐 | 告発するか、調べるか | 正義と慎重さ |
| 第3分岐 | 内通者を追うか、罠と疑うか | パラノイアの制御 |
| 第4分岐 | 組織を守るか、個人で動くか | 共同体と孤立 |

**走るモチーフ**: 灰野の通信空白／名簿の改ざん痕／セラだけが知っている「あなたの選択」

---

## 1. 作品概要

**フック**: 継承の印を受けた夜、証人名簿の一行が消えている。灰野は「内側に、整理屋がいる」と言う。セラは、あなたにだけ通知を送る。「組織を信じますか？」

**選択の意味**: 反AI組織の内側にも、最適化の論理が入り込む。疑心を乗り越えて供物へ進むか、ここで分裂するか。

---

## 2. 分岐マップ

```
START → S01（改ざんされた名簿）
  ├─ 灰野に問う → S03
  ├─ 楓に聞く → S02 → S03
  └─ セラの通知に返信 → E02

S03（内通の影）
  ├─ 告発する → S04-ACCUSE
  ├─ 独自に調べる → S04
  └─ 黙って従う → E03

S04（真相）
  ├─ 整理屋は虚構 → E05（True）→ 第7話
  ├─ 本当に内通者 → E01
  └─ [隠] セラが仕組んだ疑念 → E06
```
