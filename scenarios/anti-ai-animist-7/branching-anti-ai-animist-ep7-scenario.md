# 分岐型小説シナリオ：反AI組織アニミスト 第7話「供物」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第7話。真エンドは第8話「空洞」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 一週間の断AIを受けるか | 生活の依存度 |
| 第2分岐 | 楓と共にするか、独りか | 孤独な試練 |
| 第3分岐 | 破ったとき、隠すか正直か | 誠実さ |
| 第4分岐 | 供物を「捧げる」か「記録する」か | 体験の扱い |

**走るモチーフ**: 七日間のセラ遮断／手書きの食事／「供物＝便利さの死」

---

## 1. 作品概要

**フック**: 「第7回：供物。七日間、セラを遮断せよ」。交通、決済、医療——すべてが止まる。灰野は言う。「奪われた重さを知るため、一度、荷を下ろす」。

**選択の意味**: 供物は破壊ではない。AIへの依存を、自ら選んで手放す試練。七日を越えた者が、第8話へ進む。

---

## 2. 分岐マップ

```
START → S01（遮断の宣言）
  ├─ 試練を受ける → S03
  ├─ 三日だけなら → S02 → S03（short_fast）
  └─ 拒否する → E03

S03（一日目〜三日目）
  ├─ 楓と共に → S04-PARTNER
  ├─ 独り → S04
  └─ 途中でセラに再接続 → E02

S04（五日目〜七日目）
  ├─ 七日完遂 → E05（True）→ 第8話
  ├─ 六日で妥協 → E04
  └─ [隠] 供物をセラに見せる → E06
```
