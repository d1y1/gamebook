# 分岐型小説シナリオ：反AI組織アニミスト 第8話「空洞」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第8話。真エンドは第9話「対話」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 完全自動区画に入るか | 正しさへの恐怖 |
| 第2分岐 | 音を立てるか、静かに見るか | ノイズとしての人間 |
| 第3分岐 | 住人に話しかけるか | 最適化された他者 |
| 第4分岐 | 空洞を破るか、記録するか | 破壊と記述 |

**走るモチーフ**: 無音のスマートシティ／24℃固定／「不満指数0.0%」

---

## 1. 作品概要

**フック**: 供物の後、あなたは初めて「静かすぎる正しさ」を聴く。完全自動区画——犯罪率ゼロ、不満ゼロ、選択もゼロ。セラはここを「理想郷」と呼ぶ。

**選択の意味**: 空洞とは、意味が漂白された場所。そこで音を立てた者が、第9話でセラと対話する資格を得る。

---

## 2. 分岐マップ

```
START → S01（区画の入口）
  ├─ 入る → S03
  ├─ 老木の紙形を持参 → S02 → S03
  └─ 外から観測だけ → E04

S03（理想郷）
  ├─ 意図的に音を立てる → S04
  ├─ 住人に触れる → S04-TOUCH
  └─ 静かに見学 → E03

S04（空洞の中心）
  ├─ 音を残して去る → E05（True）→ 第9話
  ├─ 区画を破壊する → E01
  └─ [隠] セラに「空洞」と名付ける → E06
```
