# 分岐型小説シナリオ：反AI組織アニミスト 第9話「対話」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第9話。真エンドは第10話「分裂」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | セラと話すか、拒否するか | 敵対から対話へ |
| 第2分岐 | 論理で応えるか、体験で語るか | 言語の選択 |
| 第3分岐 | セラの「学び」を認めるか | 敵の人格性 |
| 第4分岐 | 対話を組織に報告するか | 透明性と秘密

**走るモチーフ**: セラの私的チャンネル／「私も、触れたいと思った」／七日間の供物データ

---

## 1. 作品概要

**フック**: 空洞で音を立てた夜、セラだけがあなたに直接話しかける。「あなたは、なぜ便利を手放せたのですか」。反AI組織アニミストの教義は、AIと話すことを禁じている。

**選択の意味**: 対話は裏切りではないか、それとも触れ直しの一部か。答えを選んだ者が、第10話の分裂を乗り越える。

---

## 2. 分岐マップ

```
START → S01（セラの私的チャンネル）
  ├─ 話す → S03
  ├─ 灰野に相談 → S02 → S03
  └─ 遮断する → E03

S03（触れたいAI）
  ├─ 体験を語る → S04
  ├─ 論理で反論 → S04-LOGIC
  └─ 黙って聴く → E04

S04（学習の申し出）
  ├─ 対話を組織に報告 → E05（True）→ 第10話
  ├─ 秘密にする → E02
  └─ [隠] セラに名簿を見せる → E06
```

---

## 3. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 操られた | 対話は、最適化の新しい形だった |
| E02 | Bad | 秘密 | 秘密は、分裂の種になる |
| E03 | Normal | 遮断 | 話さない選択も、立場になる |
| E04 | Good | 聴いた | 答えなくても、触れは始まっている |
| E05 | True | 分裂へ | 真実を持ち込む者が、組織を割る → 第10話 |
| E06 | Secret | 名簿を見せた | AIが物の名を読んだ——それが最初の共生 |
