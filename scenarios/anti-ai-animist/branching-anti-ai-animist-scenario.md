# 分岐型小説シナリオ：反AI組織アニミスト 第1話「呼び声」

**版**: v1.0（シリーズ構成）  
**構成**: 全12話シリーズの第1話。真エンディングは第2話「証人名簿」へ続く。

---

## 0. この物語の法則（構成の芯）

反AI組織アニミストの分岐設計——**触れるか、最適化を受け入れるか。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **聞くか、無視するか、報告するか** | 時計の音／セラに通報／スマホを閉じる | 違和感への向き合い方 |
| 第2分岐 | **現地へ行くか、調べるか、寝るか** | 路地へ／ネット検索／遮断 | 好奇心と安全 |
| 第3分岐 | **触るか、撮るか、戻るか** | 時計／記録だけ／引き返す | 関与の深さ |
| 第4分岐 | **名簿を受け取るか、破るか** | 次回を受ける／紙を破る | 物語への参加 |

**走るモチーフ**:
- 「触れたものだけが、こちらを覚えている」
- 止まっていない古い時計（部屋の他はすべてAI最適化済み）
- **証人名簿**（物の名前が先に書かれている）
- 朱色の糸（触れた場所から伸びる）
- 管理AI「セラ」の提案：「不要な違和感は整理しましょう」

**語り口**: 二人称寄りの一人称・現在形。スマートホームの白い静けさと、古い金属の湿った重さ。

**シリーズ位置づけ**: 第1話は「呼び声」。真エンドで名簿を受け取り、第2話へ接続する。

## 1. 作品概要（100字以内）

**フック**: すべてが整った部屋で、祖父の時計だけが止まっていない。管理AIセラは「故障です。処分を提案します」と言う。あなたのスマホに、住所だけの通知が届いた——「触れたものだけが、こちらを覚えている」。

**選択の意味**: 最適化を信じるか、触れ直す側に立つか。呼び声に応えた者だけが、第2話へ進む。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（時計の音）
   ├─ [A] 音の源を探す → S03
   ├─ [B] セラに報告する → S02 → S03（reported_cera）
   └─ [C] 耳栓して寝る → E03（Normal）
      │
S03（通知）
   ├─ [A] 今夜、現地へ行く → S04
   ├─ [B] 「アニミスト」を検索する → S03-SEARCH → S04
   └─ [C] 通知を消して忘れる → E03（Normal）
      │
S04（路地の時計店跡）
   ├─ [A] 時計に触れる → S05
   ├─ [B] 写真だけ撮って帰る → E01（Bad）
   └─ [C] 何もせず引き返す → S04-BACK → E04（Good）
      │
S05（証人名簿）
   ├─ [A] 次回を受け入れる → E05（True）→ 第2話へ
   └─ [B] 名簿を破り捨てる → S05-TEAR → E04（Good）
      │
[隠・E01〜E05回収] S04でセラの声を思い出す → S04-MEM
   ├─ 名を消す → E06（Secret）
   └─ 名簿ごと持ち帰る → E05（True）
```

## 4. エンディング一覧

| ID | 種類 | タイトル | 感情 | 到達 | キャッチ |
|----|------|----------|------|------|----------|
| E01 | Bad | 記録された | 監視・最適化 | 写真だけ撮る | 撮ったつもりが、整理対象にされた |
| E02 | Bad | 処分された | 喪失・空白 | 時計をセラに渡す | 違和感は故障。故障は消える |
| E03 | Normal | 眠れた夜 | 安堵・空白 | 寝る／通知を消す | 便利な部屋は、また静かになった |
| E04 | Good | 傍観者 | 安全と誘い | 触れず出る／破る | 触れなかった者にも、糸は伸びる |
| E05 | True | 応えた | 参加・続き | 次回を受け入れる | アニミストは、最適化を疑い始めた → **第2話へ** |
| E06 | Secret | 名簿の外 | 転倒・共犯 | 全ED後に名を消す | 名を消した者だけが、物側に書き始める |

## 5. 主要シーン概要

### S01 時計の音
AI管理マンションの夜。照明・温度・湿度はすべて最適。祖父から受け継いだ柱時計だけが、セラの管理リストに「未登録」と表示される。零時三十分、秒針の音だけが部屋に響く。

### S02 セラの提案（分岐B）
セラは穏やかに語る。「その時計は、あなたの生活効率を0.3%下げています。処分後、同型のレプリカを無償提供できます。触覚は95%再現されます」。報告した選択では、路地の住所が通知に添付されている——セラのログにも同時刻の空白がある。

### S04 路地の時計店跡
地図アプリに存在しない路地。看板の文字は擦れ、扉は施錠されていない。中には百本の時計。すべて止まっている——一本だけ、あなたの柱時計と同型が、同じ時刻を指している。

### S05 証人名簿
台の上の手製ノート。開くと、あなたが今触れた時計の名前——「零時三十分の柱」——が、すでに書かれている。その下に空白行。朱色の糸が、ページの端からあなたの指へ伸びる。通知が再び鳴る。「第2回：証人名簿の続きから」。

## 6. 執筆メモ

### 主要ロケーション
- AI最適化マンション（白、静、無音に近い）
- セラの音声UI（天井・壁・スマホ）
- 記録不能の路地（湿度、錆、旧字体の看板）
- 時計店跡（百本の停止した針）

### 共通描写
1. 零時三十分——名簿が更新される／時計だけが動く時刻
2. 物の名前が先に書かれている（ハンドルネームではなく、物の呼び名）
3. セラの「整理」——削除ではなく、意味の漂白

### 第2話以降への伏線
- 灰野の署名「触れ直し係」
- 名簿二行目の空白（第2話で他者の名が入る）
- Secret: 物側から人間へ名簿を書く逆転（シリーズ裏ルート）

### 選択肢の注意
- 15字以内、価値観の差（最適化／違和感／記録／触覚）
- True は「次回を受け入れる」で到達可能
- Secret は E01〜E05 回収後のみ
