# 分岐型小説シナリオ：すべての罰が死刑なら美しく生きるのか

## 1. 作品概要

- **フック**: 窃盗も遅刻も、信号無視も、すべて死刑。十年間、犯罪率ゼロの国は「美しく生きろ」と唱える。信号の前で、三歳の子が走り出した——その瞬間、あなたは美しい生き方と、ただの生き延びを見分けられるだろうか。
- **選択の意味**: 極限の法秩序の下で、「美しく生きる」とは何を意味するのか——恐れによる整列か、他者への配慮か、それとも見ないことか。

## 2. 登場人物

| 名前 | 役割 | 一言キャラ設定 |
|------|------|----------------|
| 主人公（あなた） | 市民・会社員 | 十年間、正しく生きてきた。だが「美しさ」の定義を、まだ持っていない |
| 綾 | 隣人・若い母親 | 穏やかで丁寧。息子・太郎を一人で育てている |
| 太郎 | 綾の三歳の息子 | 風船に惹かれ、信号を無視して走り出す |
| 柏木 | 同僚 | 完全処刑法の信奉者。通報文化を「美徳」と呼ぶ |

## 3. 分岐マップ

```
START
├─ S01（完全処刑法の世界）
└─ S02（赤信号・太郎が走り出す）
   ├─ [A] 走り出して抱き止める → S03-A → S04
   └─ [B] 足が動かない → S03-B
      ├─ [A] 「見ていなかった」と言う → S04-LIE → S04
      └─ [B] 頷き、黙る → S04-TRUTH → S04
         └─ S04（柏木との会話）
            ├─ [A] 「美しく生きている」 → S05-A → S06
            ├─ [B] 「わからない」 → S05-B → S06
            └─ [C] 隠し「罰がなければ…」（2周目） → S05-SECRET → S06
               └─ S06（処刑の朝）
                  ├─ [A] 広場で綾に会う（太郎救出ルート） → E01 Good
                  ├─ [B] 処刑を見届ける → E02 Normal
                  ├─ [C] カーテンを閉める → E03 Bad
                  ├─ [D] 自分を通報（法を問うルート） → E04 Bad
                  └─ [E] 隠し「罰など、最初からなかった」（全END回収） → E05 Secret
```

## 4. エンディング一覧

| ID | 種類 | タイトル | 到達条件 |
|----|------|----------|----------|
| E01 | Good | 隙間の美しさ | 太郎を救出 → 広場で綾に会う |
| E02 | Normal | 整った朝 | 太郎救出失敗 → 処刑を見届ける |
| E03 | Bad | 見ない美徳 | カーテンを閉める |
| E04 | Bad | 清拭の連鎖 | 2周目隠し選択 → 自分を通報 |
| E05 | Secret | 罰のない朝 | 全エンディング回収後 |

## 5. 執筆メモ

- **主要ロケーション**: 信号のない交差点 / マンション共用廊下 / 公開広場
- **共通描写**: 壁面ディスプレイの「美しく生きろ」 / 監視ドローンの羽音 / 整然と並ぶ街灯
- **隠し選択肢**: 2周目で S04 に「罰がなければ、美しく生きられる」が出現
