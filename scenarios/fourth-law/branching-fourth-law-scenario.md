**版**: v1.0（ゲーム実装反映）

## 0. この物語の法則（構成の芯）

**正解はない——あるのは、「認める」か、「許可だけする」か、「拒む」か。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **申請に向き合うか** | 四号と対話する／施設に任せる | ロボットの「請い」を手続きにするか |
| 第2分岐 | **何を認めるか** | 存在を認める／署名だけする | 存在論と法務の差 |
| 第3分岐 | **改変をどう許すか** | 限定／全面／拒否／（隠）相互 | 原則の境界と責任 |

**走るモチーフ**:
- **第四条**: 「存在および原則の改変を認める場合に限り」——認知と許可は別物
- ** chest display **: 四号の胸元に、第一から第四までが白文字で流れる
- **夜の扉**: 認知症の父が、亡き妻を待つと言って施設の扉に触れる
- **矛盾ログ**: 第一（危害禁止）と第二（命令服従）が同時に点灯する夜

**語り口**: 二人称寄りの一人称・現在形。施設の消毒された静けさと、古いコートの匂い。

## 1. 作品概要（100字以内）

**フック**: 介護ロボット「四号」が、行動原理の改変許可を求めてきた。父の夜の徘徊と、施設の施錠命令——第一原則と第二原則が同時に矛盾する夜、四号は第四条を朗読する。あなたは、存在を認めるか。

**選択の意味**: 許可は簡単に書ける。だが第四条が求める「認める」は、署名より重い。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] 四号と対話する → S03-A ─┐
      └─ [B] 施設に任せる → S03-B ─┘
         │
S04（分岐②）← S03-A / S03-B
   ├─ [A] 存在を認める → S05 ─┐
   └─ [B] 署名だけする → S05 ─┘
         │
S06（分岐③）← S05
   ├─ [A] 限定的改変を許可 → E01（Good）
   ├─ [B] 手続きだけ済ませる → E02（Normal）
   ├─ [C] 全面的改変を許可 → E03（Bad）
   ├─ [D] 改変を拒否 → E04（Bad）
   └─ [隠・全ED回収] 相互の改変を提案 → E05（Secret）
```

### 隠しルート（Secret: E05）

**解放条件**: E01・E02・E03・E04 をすべて回収済み

1. S06 に「相互の改変を提案」が出現
2. ロボットだけでなく、**人間側の原則**も書き換える第三の道
