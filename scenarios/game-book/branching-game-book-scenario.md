# 分岐型小説シナリオ：ゲームブック

**版**: v1.0（ゲーム実装反映）

---

## 0. この物語の法則（構成の芯）

**ゲームブックを読み尽くすほど、選択の重みが薄れる。全エンディングを回収するほど、物語が作業になる。だが「正解を真剣に選ぶ」ことには、まだ意味がある。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **どう読み始めるか** | クリア狙い／Bad End巡り | 目的意識と好奇心 |
| 第2分岐 | **迷宮・クイズでどうするか** | 正解へ／未読へ／手抜き | 誠実さと衝動 |
| 第3分岐 | **周回が作業になった時** | 続ける／やめる／読み方を変える | 完遂と手放し |
| 第4分岐 | **最後にどう選ぶか** | 真剣に正解／全回収／本を閉じる／（隠）裏表紙 | 選択の意味の再発見 |

**走るモチーフ**:
- **ページ番号**: 選択肢の先に書かれた数字（→ 63ページへ）
- **ゲームオーバー**: 失敗の軽さと、いつか失われる悔しさ
- **指し折り**: 周回の痕跡、攻略の地図
- **本を閉じる**: 読むことと生きることの境界

**語り口**: 一人称（私）。内省的。ゲームブックの仕組みを自然に語る。最後は静かな決意で締める。

## 1. 作品概要

**フック**: ゲームブックをご存知だろうか。物語と選択肢があり、ページを飛び、迷路とクイズを越え、クリアもゲームオーバーもとんでもない結末もある。やり慣れると正解を選びたくなくなる——いま、私は正解を真剣に選ぶことを楽しもうと思う。

**選択の意味**: 全てを見たい欲と、一つの道を真剣に歩む誠実さ。読むことと、選ぶことの重み。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] 今度こそクリアを目指す → S03-A
      └─ [B] いちばん遠いBad Endから → S03-B
         │
S03-A（分岐②）              S03-B（自動）→ S04-B
   ├─ [A] 63ページへ（正解）→ S04-A
   └─ [B] 42ページへ（未読）→ S04-C
         │
S05（合流・分岐③）← S04-A / S04-B / S04-C
   ├─ [A] もう一度、正解を選んでみる → E01（Good）
   ├─ [B] 全部見るまでやめない → E03（Bad）
   ├─ [C] 本を閉じて、現実を選ぶ → E02（Normal）
   └─ [隠・全ED回収] 裏表紙の文字を読む → E04（Secret）
```

### 隠しルート（Secret: E04）

**解放条件**: E01・E02・E03 をすべて回収済み

1. 上記条件を満たした状態で S05 に「裏表紙の文字を読む」が出現
2. ゲームブックの外側——**読者自身の選択**に気づく第四の道
