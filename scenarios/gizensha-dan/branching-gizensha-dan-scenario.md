# 分岐型小説シナリオ：偽善者団

**版**: v1.0

---

## 0. この物語の法則（構成の芯）

月会費三千円。**弱い人に優しくすることで得る優越感**を、隠さず共有するボランティア団体——それが「偽善者団」だ。ホームレス支援、擁護施設、介護施設への物資手配と手伝い。会員は皆、自分がいい人間だと**自覚している**。だからこそ、偽善を認めたまま手を動かせる。

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **入るか、見るか** | 入会して初活動／見学だけ | 善意と優越感の距離 |
| 第2分岐 | **どう手伝うか** | 黙々と運ぶ／記録係／利用者と話す | 行為と見せ方の比重 |
| 第3分岐 | **偽善をどう扱うか** | 自覚して続ける／断罪して去る／撮影だけ | 善行の動機を認めるか |

**走るモチーフ**:
- 月会費三千円：領収書に「寄付金控除可」と書かれている
- 黄色いベスト：胸に「偽善者団」の刺繍。写真映えする
- 優越感：代表の定番フレーズ「弱い人に優しくする、その優越感に浸れ」
- SNS：#偽善者団 #今日もいい人でいた

**語り口**: 一人称・現在形。自嘲と観察。説教はしない。代表のセリフだけがやや大げさ。

## 1. 作品概要（100字以内）

**フック**: 月会費三千円。「弱い人に優しくする優越感に浸れ」——そう宣言するボランティア団体がある。ホームレス支援、擁護施設、介護施設。会員は皆、自分がいい人間だと自覚している。あなたは、入会するか。

**選択の意味**: 手を動かすか、記録するか、去るか。正解はなく、残るのは「なぜ手を伸ばしたか」だけ。

## 4. 分岐マップ（v1.0）

```

└─ S01（自動）→ S02

      ├─ [A] 入会して初活動へ → S03-JOIN
      ├─ [B] 見学だけする → S03-OBSERVE
      └─ [隠・2周目] 領収書の「寄付金控除」を確認 → S-SECRET-01
         │
S03-JOIN ─┬─ [A] 物資運びを黙々とやる → S04-WORK
          ├─ [B] 記録係を引き受ける → S04-PHOTO
          └─ [C] 利用者と話す → S04-TALK
         │
S03-OBSERVE ─┬─ [A] 代表の説明を聞く → S04-BRIEF
             └─ [B] 会員の投稿を眺める → S04-SNS
         │
S04-* ─→ S05（収束）
         │
S05（分岐③）
├─ [A] 偽善を認めたまま続ける → E01
├─ [B] 優越感を共有する場として居る → E02
├─ [C] 撮影だけして手は動かさない → E03
├─ [D] 全員を断罪して去る → E04
└─ [隠・全ED回収] 代表に「本物の偽善者は誰か」と問う → E05
```
