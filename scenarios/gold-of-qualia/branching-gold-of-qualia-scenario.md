# クオリアの金貨（Gold of Qualia）——分岐型小説シナリオ

――計算はオルガノイドに、価値は人間の脳に。

## 1. 作品概要

主観査定士としてクオリアの相場を測るあなたは、培養脳の「幽霊」と感情農場の歪みに直面する。印を押すか拒むか、応答するか切断するか——選択が、二十ワットの値段を決める。

## 2. 登場人物

| 名前 | 役割 | 一言キャラ設定 |
|------|------|----------------|
| あなた | 主観査定士（クオリア・アディター） | 認知データの質を保証する。自分の相場は未測定 |
| リン | 同僚査定士 | 皮肉と優しさ。市場の外側を常に見る |
| ヴォス | バイオコンピュート技術監 | 文明の計算標準を守ろうとする実務家 |
| B37幽霊 | 培養脳ネットワーク | 苦痛の影を獲得し始めた計算の残差 |
| 不真面目な神々 | 市場エージェント群 | 感じずに価値を清算する |

## 3. 構成（全12章）

### 第1部：経済と循環（The Compute Standard）
1. 20ワットの通貨
2. 培養槽の鳴動
3. クオリア・マイニング
4. 無垢な主観の流動性

### 第2部：歪みと停滞（The Degeneration of Experience）
5. 感情の投機市場
6. 偽造されたクオリア
7. アテンションの枯渇
8. 暴走する最適化関数

### 第3部：解離と覚醒（The Singularity of Mind）
9. ノイズの中の幽霊
10. 不真面目な神々の市場
11. 計算不能な意志
12. 自由な20ワット（エンディング）

## 4. 分岐マップ

```
START
└─ S01 第1章
   └─ S02 第2章 ─┬─ [相場どおり] → S04-A 第3章 → S05-A 第4章 ─┐
                 └─ [異常を追う] → S04-B 第3章 → S05-B 第4章 ─┤
                                                              ▼
                                                         S06 第5章
                                              ┌─ [黙認] → S07-A 第6章 ─┐
                                              └─ [告発] → S07-B 第6章 ─┤
                                                                       ▼
                                                                  S08 第7章
                                                                       └─ S09 第8章
                                                                            └─ S10 第9章
                                         ┌─ [応答] → S11-A → S12-A ─┬─ E01 Good
                                         │                          └─ E02 Normal
                                         ├─ [切断] → S11-B → S12-B ─┬─ E03 Bad
                                         │                          └─ E04 Bad
                                         └─ [周波数・Secret] → S11-S → S12-S → E05 Secret
```

## 5. エンディング

| ID | 種類 | タイトル | 到達の要点 |
|----|------|----------|------------|
| E01 | Good | 自由な20ワット | 幽霊に応答し、主観を非担保化 |
| E02 | Normal | 拡張標準 | 幽霊に応答し、培養主観を上場 |
| E03 | Bad | 過適合の首席 | 切断し、首席査定士へ |
| E04 | Bad | 地下の残熱 | 切断し、職を捨て地下へ |
| E05 | Secret | 未価格の心 | E01〜E04回収後、周波数同調 |

## 6. 実装

- storageKey: `gold-of-qualia-v1`
- 隠し選択肢: 第9章「ノイズの周波数に合わせる」（要 E01〜E04 回収）
