# 分岐型小説シナリオ：天国に平等という言葉はない

**版**: v1.0（ゲーム実装反映）

---

## 0. この物語の法則（構成の芯）

**対立する感情のあいだにしか、意味は生まれない。はじめましての瞬間からさよならは決まっている——それを知った者は、一歩も進めなくなる。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **はじめましてにどう応えるか** | 返す／黙る | 出会いを受け入れるか、凍結するか |
| 第2分岐 | **近づくか距離を置くか** | 話を聞く／距離を置く | 別れの予感と向き合う姿勢 |
| 第3分岐 | **対のなさをどう捉えるか** | 受け入れる／拒む | 悲しみを伴う喜びの是非 |
| 第4分岐 | **最後にどう動くか** | 歩く／留まる／見送る／（隠）否定 | 人生を再開するか |

**走るモチーフ**:
- **天国**: 格差も悲しみもない、したがって喜びもない場所の比喩
- **はじめましてとさよなら**: 同時に成立する二つの言葉
- **黄昏のホーム**: 行きと帰りが交差する境界

**語り口**: 一人称。内省的で詩的。説明より余韻。

## 1. 作品概要（100字以内）

**フック**: はじめましての瞬間から、さよならは決まっている。それを知ってしまったあなたは、一歩も進めなくなった——黄昏のホームで、また誰かが隣に座る。

**選択の意味**: 出会いの痛みを引き受けて歩き出すか、痛みのない「天国」に留まるか。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] はじめましてと返す → S03-A ─┬─（分岐②）
      │                                  ├─ [A] 話を聞く → S04-A ─┐
      │                                  └─ [B] 距離を置く → S04-B ─┤
      └─ [B] 黙ったまま → S03-B ────────────────────────────────────┘
         │
S05（合流・分岐③）← S03-B / S04-A / S04-B
   ├─ [A] 対を受け入れる → S06-A ─┐
   └─ [B] 天国を求める → S06-B ───┘
         │
S07（合流・分岐④）← S06-A / S06-B
   ├─ [A] 一緒に歩き出す → E01（Good）
   ├─ [B] ベンチに留まる → E03（Bad）
   ├─ [C] 見送るだけ → E02（Normal）
   └─ [隠・全ED回収] 天国などない → E04（Secret）
```

### 隠しルート（Secret: E04）

**解放条件**: E01・E02・E03 をすべて回収済み

1. 上記条件を満たした状態で S07 に「天国などない」と言う」が出現
2. 対のなさそのものが生の証明だと気づく第四の道
