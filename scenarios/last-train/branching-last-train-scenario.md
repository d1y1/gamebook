# 分岐型小説シナリオ：終電の向こう側

**版**: v1.0

---

## 0. この物語の法則（構成の芯）

深夜の東京、終電に飛び乗った瞬間から始まる一夜の物語。**偶然の出会いが、選択によって「一夜の冒険」にも「運命の出会い」にも「後悔の朝」にもなる。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **彼女にどう接するか** | 話しかける／距離を置く | 人との距離感 |
| 第2分岐 | **彼女の事情にどう向き合うか** | 踏み込む／見守る | 優しさの形 |
| 第3分岐 | **朝が来たときどうするか** | 連絡先を聞く／別れる | 関係性への覚悟 |

**走るモチーフ**（各シーンに散らす）:
- 終電の車内：空いた座席、窓に映る二人の影、車掌のアナウンス
- 深夜の街：シャッターの降りた商店街、コンビニの光、誰もいない公園
- 夜明けの空：紫から橙に変わるグラデーション、始発電車の音
- 彼女のスーツケース：小さな傷、剥がれかけのステッカー

**語り口**: 一人称・現在形。等身大の社会人、内心の揺れを丁寧に。

## 1. 作品概要（100字以内）

**フック**: 金曜深夜、終電に飛び乗った瞬間——ドアに挟まれそうな女性の手を引いた。彼女はスーツケースを抱え、目が赤かった。「ありがとう」。その一言から、長い夜が始まる。

**選択の意味**: 見知らぬ人にどこまで踏み込むか。一夜の優しさは、朝になって何を残すのか。

## 3. 分岐マップ（v1.0）

**三つの問いで読むマップ** — ①彼女にどう接するか → ②事情にどう向き合うか → ③朝が来たとき

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] 隣に座って話しかける → S03-TALK
      ├─ [B] 距離を置いて見守る → S03-WATCH
      └─ [隠・条件付] 「さっき、泣いてましたよね」 → S-SECRET-01 → S-SECRET-02 → E05
         │
S03-TALK ─┬─ [A] 事情を聞く → S04-ASK
          └─ [B] 世間話で気を紛らわせる → S04-CASUAL
         │
S03-WATCH ─┬─ [A] 降りる駅で声をかける → S04-STATION
           └─ [B] そのまま見送る → E03
         │
S04-ASK ─┬─ [A] 一緒に歩こうと提案 → S05-WALK → E01
         └─ [B] 連絡先を渡して別れる → E02
S04-CASUAL ┬─ [A] 朝まで付き合うと言う → S05-ALLNIGHT → E01
           └─ [B] 終点で別れる → E02
S04-STATION ┬─ [A] 「送りましょうか」 → S05-WALK → E01
            └─ [B] 「気をつけて」で別れる → E04
```

### 隠しルート（Secret: E05）

**解放条件**: E01 と E03 の両方を回収済み

1. 上記条件を満たした状態で S02 に「さっき、泣いてましたよね」が出現
2. S-SECRET-01 で凛の本当の事情（父との確執、元上司からの逃避）を聞く
3. S-SECRET-02 で翔が「じゃあ、逃げるのを手伝う」と言う → E05

## 5. 執筆メモ

### 主要ロケーション

- 終電の車内（山手線、最終便）
- 深夜の駅（池袋駅構内）
- 24時間営業のファミレス
- 誰もいない公園（駅から徒歩5分）
- 夜明けのホーム（始発を待つ）

### 共通描写（再利用可）

1. **終電の空気**: 週末の疲れた乗客、窓の結露、規則的な揺れ
2. **深夜のコンビニ**: 蛍光灯の眩しさ、温かい缶コーヒー、店員の無関心
3. **夜明けの空**: 紫から橙へ、ビルの輪郭、始発のアナウンス

### 凛のバックストーリー

- 地方の老舗旅館の一人娘
- 東京の旅行会社に就職したが、上司のパワハラで退職
- 父からは「帰ってこなくていい。お前は自分の人生を生きろ」と言われた
- 本当は帰りたい。でも、帰れない。だから終電に乗った

### リプレイ設計

- E01 は王道のGood End。「出会い」を選び続けた報酬
- E03 は最も短いルート。「関わらない」選択の結末
- E05 は「踏み込んだ先」にある、もう一つの物語
