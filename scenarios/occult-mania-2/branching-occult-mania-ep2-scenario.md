# 分岐型小説シナリオ：オカルトマニア 第2話「名簿の続き」

**版**: v1.0（ゲーム実装反映）  
**構成**: 全6話シリーズの第2話。真エンディングは第3話「接触」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 入るか、聞くか、欠席か | 好奇心と退避 |
| 第2分岐 | 一緒に読むか、独りか、逃げるか | 共闘と孤独 |
| 第3分岐 | 相手を選ぶか、自分か、選ばないか | 犠牲と引き受ける覚悟 |
| 第4分岐 | 第3回を受けるか、閉じるか | 物語への参加 |

**走るモチーフ**: 接触候補／記号の進行（招待→接触→観察→済）／黒井の済の隣の空白

---

## 1. 作品概要

**フック**: 「第2回は、名簿の続きから」。同じ扉の向こうで、接触候補の名前が並び、記号が書き換えられていく。

**選択の意味**: 続きを読む者は、一人を選ばされる。選ばれた側だけが、第3話へ進む。

---

## 2. 分岐マップ

```
START → S01
  ├─ 入る → S03
  ├─ 黒井に聞く → S02 → S03
  └─ 帰る → E03
S03
  ├─ 一緒に読む → S04 → 相手/自分/石 → E02 / S05 / E04
  ├─ 無視 → S04-ALONE → S05
  └─ 出る → E01
S05
  ├─ 第3回を受ける → E05（True）→ 第3話
  ├─ 閉じる → S05-CLOSE → E04
  └─ [隠] 空白を探す → S05-GAP → E06 / E05
```

---

## 3. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 逃げた続き | 続きを読まずに逃げても、記号は進む |
| E02 | Bad | 差し出した | 選んだつもりが、選ばせていた |
| E03 | Normal | 第2回欠席 | 欠席しても、候補からは外れない |
| E04 | Good | 保留 | 選ばなければ、少しだけ遅れる |
| E05 | True | 接触へ | 名簿の続きは、触れる話になる → 第3話 |
| E06 | Secret | 空白に書いた | 済の隣に書く者は、もうマニアではない |

---

## 4. シリーズ位置

- 前話: 第1話「きっかけ」True「選ばれた」
- 次話: 第3話「接触」（True接続）
- 裏: Secretは案内人候補ルートの強化
