# 分岐型小説シナリオ：オカルトマニア 第3話「接触」

**版**: v1.0（ゲーム実装反映）  
**構成**: 全6話シリーズの第3話。真エンディングは第4話「観察」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 入るか、聞くか、帰るか | 覚悟と退避 |
| 第2分岐 | 何に触れるか／触れないか | 関与の形（能動／受動／回避） |
| 第3分岐 | 受けるか、離すか | 契約への同意 |
| 第4分岐 | 案内人側の指紋を押すか | 逆接触の資格 |

**走るモチーフ**: 交換としての接触／赤い糸／体温を覚えている石／背中の温度／黒井の残り指紋

---

## 1. 作品概要

**フック**: 「触れないと、触れられる」。同じ扉の向こうで、赤い線が指に絡み、黒い石が黒井の体温をまだ覚えている。触れる者と、触れられる者——今夜、どちらの側に立つ。

**選択の意味**: 接触は片手からでも成立する。両手を通した者だけが、次の「観察」へ進む。

---

## 2. 分岐マップ

```
START → S01（扉の前・一人）
  ├─ 扉を開ける → S03
  ├─ 黒井にもう一度聞く → S02 → S03（asked_kuroi）
  └─ 引き返す → E03（Normal）

S03（一人の部屋）
  ├─ 黒い石に触れる → E02（Bad）
  ├─ 赤い線に触れる → S04（touched_line）→ 受ける／離す
  ├─ 触れずに待つ → S04-WAIT（waited）→ S05
  └─ 部屋を出る → E01（Bad）

S04
  ├─ このまま受ける → S05
  └─ 手を離す → E04（Good）

S05（触れられる番）
  ├─ 第4回を受ける → E05（True）→ 第4話へ
  ├─ 逃げる → E04（Good）
  └─ [隠・E01〜E05回収] 黒井の残りを探す → S05-KUROI
      ├─ 案内人側で押す → E06（Secret）
      └─ 石を戻して帰る → E05（left_print）
```

---

## 3. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 扉に触られた | 触れずに逃げても、触られる |
| E02 | Bad | 標本 | 交換ではなく、回収された |
| E03 | Normal | 第3回欠席 | 欠席しても、契約は片手に残る |
| E04 | Good | 片手の契約 | 半分だけの接触は、半分だけ猶予される |
| E05 | True | 触れられた | 触れる／触れられる、両方の側になる → 第4話 |
| E06 | Secret | 逆接触 | 触れる側の側から、触れ返す |

---

## 4. 執筆メモ

### 主要ロケーション
- 深夜二時の南京錠の扉（前2話と同じ）
- 一人の空き部屋（隅の男はいない）
- 台の下＝黒井の焦げた指紋（Secret鍵）
- 暗号化チャット（黒井）

### 共通描写
1. 「触れないと、触れられる」——契約の順番
2. 赤い糸／赤い線が指・胸に絡む物理的接触
3. 体温を覚えている石（黒井の残留）
4. 背中の温度・肩甲骨のあいだの手

### 第4話以降への伏線
- 「次は、観察されろ」——観察の記号への移行
- Secret: 案内人登録の三段階（消去／空白／指紋）
- 第二の扉の住所（Secret後半で示唆）

### 選択肢の注意
- 15字以内、価値観の差（能動接触／受動接触／回避／逃走）
- Trueは本編の「受ける」で到達可能
- Secretは E01〜E05 回収後、S05に出現
