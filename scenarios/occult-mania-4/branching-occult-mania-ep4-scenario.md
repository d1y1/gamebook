# 分岐型小説シナリオ：オカルトマニア 第4話「観察」

**版**: v1.0（ゲーム実装反映）  
**構成**: 全6話シリーズの第4話。真エンディングは第5話「済の印」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 向かうか、聞くか、動かないか | 観察者としての起動 |
| 第2分岐 | 撮るか、目で見るか、声を出すか | 距離の取り方 |
| 第3分岐 | 済を確定、消す、投稿する | 記録との共犯度 |
| 第4分岐 | 案内人の投稿を送るか | 立場の反転 |

**走るモチーフ**: 双方向の視線／ファインダー越しに映る自分／窓ガラスの二重像／削除と保留／案内人の新規スレ

---

## 1. 作品概要

**フック**: 「第4回：観察。扉の外から」。向かいの空き家の窓辺に、三脚がある。撮る者は、撮られる——ファインダーの中で、自分自身が部屋の隅に立っている。

**選択の意味**: 観察を通した者だけが、次の「済の印」へ進む。ログを消せば、案内は保留になる。投稿すれば、案内人の側に立つ。

---

## 2. 分岐マップ

```
START → S01（自室のモニター）
  ├─ 向かいの部屋へ → S03
  ├─ 黒井にもう一度聞く → S02 → S03（asked_kuroi）
  └─ 今夜は動かない → E03（Normal）

S03（三脚のある窓辺）
  ├─ カメラで撮る → S04（filmed）→ S05
  ├─ 目だけで観察 → E02（Bad）
  └─ 窓から声を掛ける → E01（Bad）

S05（済の記号）
  ├─ 済の記号を確定 → E05（True）→ 第5話へ
  ├─ 観察ログを消す → S05-DEL（deleted_logs）→ E04（Good）
  └─ [隠・E01〜E05回収] 自分が投稿する側へ → S05-POST
      ├─ 住所を書いて送信 → E06（Secret）
      └─ 画面を閉じる → E05（walked_away）
```

## 3. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 呼びかけた者 | 観察者が声を出すと、対象になる |
| E02 | Bad | 目が記録した | カメラを回さない者は、自分が記録媒体になる |
| E03 | Normal | 第4回欠席 | 観察を欠席しても、板は観察を続ける |
| E04 | Good | ログを消した | 済を一つ飛ばした者は、空白の隣に立てる |
| E05 | True | 済の印 | 観察を通した者は、次に自分の済を受ける → 第5話 |
| E06 | Secret | 掲示板の側 | 観察者は、いつか投稿者になる |

## 4. 執筆メモ

### 主要ロケーション
- 深夜の自室（モニター光・観察スレ）
- 向かいの空き家の二階（三脚・ビデオカメラ・窓）
- 扉の前（窓越しに見える）
- 暗号化チャット（黒井）

### 共通描写
1. カメラのファインダー越しに映る、自分自身
2. 窓ガラスの二重像（自分の顔と、ずれるまばたき）
3. 板の自動更新（記録済／削除／代替観測）
4. 撮る／撮られる／記録媒体になる、の三段階

### 第5話以降への伏線
- 「今度は、部屋の中で待て」——次回の対象化
- Secret: 案内人の三段階（消去／空白／指紋）＋観察の権限＝投稿権
- 第二の扉の住所（第3話Secretから継承）

### 選択肢の注意
- 15字以内、価値観の差（記録／回避／介入／削除／投稿）
- True は「済の記号を確定」で本編到達
- Secret は E01〜E05 回収後、S05に「投稿する側へ」が出現
