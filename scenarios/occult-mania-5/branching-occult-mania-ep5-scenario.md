# 分岐型小説シナリオ：オカルトマニア 第5話「済の印」

**版**: v1.0（ゲーム実装反映）  
**構成**: 全6話シリーズの第5話。真エンディングは最終回・第6話「本物だけ残す」へ続く。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 儀式に赴くか、聞くか、欠席か | 覚悟と退避 |
| 第2分岐 | 判子を受けるか、盗るか、拒むか | 服従・介入・反抗 |
| 第3分岐 | 印肉に押すか、逃げるか | 儀式の完遂 |
| 第4分岐 | 済を押すか、保留か、案内人欄へ落とすか | 名簿の抜け道 |

**走るモチーフ**: 朱色の紐／黒い印肉／二本の判子／案内人欄／黒井の「済」の隣の空白／記号の確定（招待→接触→観察→済）

---

## 1. 作品概要

**フック**: 観察は済んだ。次は「済」の押印——マニア名簿の最終工程。台の上には、朱ではなく黒い印肉と、二本の判子（自分の「済」、そして黒井のハンドル）。押すか、逃げるか、案内人欄に落とすか。

**選択の意味**: 済を受ければ書く側へ移る（最終回）。押さなければ名簿の外側にとどまるが、自動押印は迫る。案内人欄に押した者は、済を経ずに案内人になる——観察を飛ばした裏道。

---

## 2. 分岐マップ

```
START → S01
  ├─ 扉を開ける → S03
  ├─ 黒井に確かめる → S02 → S03
  └─ 儀式に行かない → E03（Normal）

S03（儀式の台：印肉／済の判子／黒井の判子）
  ├─ 「済」の判子を受ける → S04
  ├─ 黒井の判子を取る → S04-STEAL → S05
  └─ 儀式を拒む → E01（Bad）

S04（印肉）
  ├─ 朱色の升目に押す → S05
  └─ 判子を戻して逃げる → E02（Bad）

S05（押印の直前）
  ├─ 自分の升目に押す → E05（True）→ 第6話
  ├─ 押さずに保留する → S05-HOLD → E04（Good）
  └─ [隠] 案内人欄に押す → E06（Secret）
```

## 3. エンディング一覧

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|
| E01 | Bad | 拒んだ標本 | 拒んだ者は、外れる代わりに、固定される |
| E02 | Bad | 逃げた儀式 | 押しかけて逃げた者は、押され続ける |
| E03 | Normal | 儀式欠席 | 欠席は、済を保留するだけ |
| E04 | Good | 保留の済 | 押さなかった判子は、名簿の端に残る |
| E05 | True | 済を受ける | 判子は押された。次は、書く側だ → 第6話 |
| E06 | Secret | 案内人欄 | 観察を越えず、案内人欄に押した者 |

---

## 4. シリーズ位置

- 前話: 第4話「観察」True「観察：了」
- 次話: 第6話「本物だけ残す」（最終回・True接続）
- 裏: Secretは「済を経ずに案内人になった者」の裏道ルート——最終回への別解として結線。
