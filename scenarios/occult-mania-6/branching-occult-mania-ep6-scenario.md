# 分岐型小説シナリオ：オカルトマニア 第6話「本物だけ残す」（シリーズ最終回）

**版**: v1.0（ゲーム実装反映）  
**構成**: 全6話シリーズの最終話。真エンディングでシリーズ完結（全6話・完）。隠しエンディングは時間の環を明かす。

---

## 0. この物語の法則

| 段階 | 問い | 読者に試されるもの |
|------|------|-------------------|
| 第1分岐 | 案内人権限を使うか、会うか、捨てるか | 承継・別れ・棄権 |
| 第2分岐 | 読むか、灯すか、座るか | 履歴・破却・服従 |
| 第3分岐 | どの頁に手をかけるか | 過去・未来・起源 |
| 第4分岐 | 扉を閉じるか、自分を抜くか | 犠牲を伴う完結・自由 |

**走るモチーフ（全話回収）**: 南京錠／深夜二時／マニア名簿（招待→接触→観察→済→案内人）／黒井の空白／黒い石／新聞切り抜きと赤い線／「本物だけ残す。住所はこれ」／案内人ダッシュボード／五冊の名簿

## 1. 作品概要

**フック**: 「本物だけ残す」——それは、生き延びるための呪文ではなく、書き手を選別する側の宣言だった。案内人権限を握った最後の夜、五冊のマニア名簿と、閉まらない扉。

**選択の意味**: 「本物」の意味を、名簿の側から読み直す。書き手として承継するか、名簿ごと灯して扉を閉じるか、自分だけ抜けて傍観者に戻るか、環の起源に気づくか。

---

## 2. 分岐マップ

```
START → S01（案内人権限を得た朝）
  ├─ 扉へ向かう → S03
  ├─ 黒井に会いに行く → S02 → S03
  └─ 権限を捨てて眠る → E03（Normal）

S03（最終回の扉：五冊の名簿）
  ├─ 名簿を読む → S04
  ├─ 名簿に火を用意する → S04-BURN → S04
  └─ 座って次のスレを立てる → E02（Bad・無限投稿）

S04（本物の意味）
  ├─ 黒井の頁を破る → S05
  ├─ 五冊目の巻末を見る → E01（Bad・永久標本）
  └─ [隠] 一冊目の最初の頁 → E06（Secret・時間の環）

S05（本物だけ残す）
  ├─ 扉ごと名簿を灯す → E05（True・全6話・完）
  └─ 自分の頁だけ破って出る → E04（Good・傍観者へ帰還）
```

| ID | 種類 | タイトル | キャッチ |
|----|------|----------|----------|

## 4. シリーズ完結ノート

- 前話: 第5話「済の印」True「済を受ける」
- 本話: シリーズ最終回。Trueで扉を閉じ、名簿の外で本物だけが残る（＝残った者＝案内人になり損ねた「鍵」）。
- Secret: 「本物だけ残す。住所はこれ」の下書きが自分の癖の字であり、時間の環を明かす——第1話の起点は、最終話の主人公から始まっていた。
- 各エンディングでの黒井の帰結:
  - True: 黒井の名は名簿から抜け、切り抜きの数字が空白に戻る。
  - Good: 黒井を助けた場合は先輩は抜ける、会わなかった場合は名簿の一行目に残る。
  - Bad×2: 黒井の帰結は未処理のまま、名簿は循環を続ける。
  - Normal: 黒井とは会わずに離脱、掲示板は他者に継がれる。
  - Secret: 黒井は「二番目」だったと明かし、環の外へ穏やかに退場。
