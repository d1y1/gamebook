# 分岐型小説シナリオ：オカルトマニア 第1話「きっかけ」

**版**: v1.0（ゲーム実装反映）  
**構成**: 全6話シリーズの第1話。真エンディングは第2話へ続く。

---

## 0. この物語の法則（構成の芯）

オカルトマニアの分岐設計——**見物か、選ばれる側か。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **行くか、聞くか、寝るか** | 現地へ／黒井に聞く／スレを閉じる | 好奇心と慎重さ |
| 第2分岐 | **開けるか、撮るか、戻るか** | 扉を開ける／写真だけ／引き返す | リスク許容度 |
| 第3分岐 | **読むか、触るか、出るか** | ノート／石／触れず | 関与の深さ |
| 第4分岐 | **受け入れるか、破るか** | 次回を受ける／ページを破る | 物語への参加 |

**走るモチーフ**:
- 「本物だけ残す」——掲示板の一行招待
- 南京錠が開いている扉
- **マニア名簿**（ハンドルネームが先に書かれている）
- 黒井の警告：「選ばれる側になる」

**語り口**: 二人称寄りの一人称・現在〜過去。深夜のモニター光と住宅街の静けさ。

**シリーズ位置づけ**: 第1話は「きっかけ」。真エンドで招待を受け、第2話「名簿の続き」へ接続する。

## 1. 作品概要（100字以内）

**フック**: 掲示板に住所だけが書かれたスレが立った。「本物だけ残す」。オカルトマニアのあなたは、行かないわけにはいかない。

**選択の意味**: 見物で終わるか、名簿に名を残すか。きっかけを掴んだ者だけが、第2話へ進む。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（掲示板）
   ├─ [A] 今夜、現地へ行く → S03
   ├─ [B] 先輩の黒井に聞く → S02 → S03（asked_kuroi）
   └─ [C] スレを閉じて寝る → E03（Normal）
      │
S03（南京錠の扉）
   ├─ [A] 扉を開ける → S04
   ├─ [B] 写真だけ撮って帰る → E01（Bad）
   └─ [C] 何もせず引き返す → S03-BACK → E03（Normal）
      │
S04（中の部屋）
   ├─ [A] ノートを開く → S05
   ├─ [B] 黒い石に触れる → E02（Bad）
   ├─ [C] 何も触らず出る → E04（Good）
   └─ [隠・E01〜E05回収] 黒井の言葉を思い出す → S04-MEM
      ├─ 名前を消す → E06（Secret）
      └─ 名簿ごと持ち帰る → E05（True）
      │
S05（マニア名簿）
   ├─ [A] 次回を受け入れる → E05（True）→ 第2話へ
   └─ [B] ページを破り捨てる → S05-TEAR → E04（Good）
```

## 4. エンディング一覧

| ID | 種類 | タイトル | 感情 | 到達 | キャッチ |
|----|------|----------|------|------|----------|
| E01 | Bad | 写された | 追跡・監視 | 写真だけ撮る | 撮ったつもりが、撮られていた |
| E02 | Bad | 触れた | 身体化・汚染 | 黒い石に触る | 冷たい石は、手放しても残る |
| E03 | Normal | 引き返した | 未完・安堵 | 寝る／引き返す | 今夜は、マニアでいられなかった |
| E04 | Good | 傍観者 | 安全と誘い | 触れず出る／破る | 触れずに出た者は、また呼ばれる |
| E05 | True | 選ばれた | 参加・続き | 次回を受け入れる | マニアは、見物をやめた → **第2話へ** |
| E06 | Secret | 名簿の外 | 転倒・共犯 | 全ED後に名を消す | 名前を消した者だけが、書き手になる |

## 5. 執筆メモ

### 主要ロケーション
- 深夜の自室（モニター光）
- 暗号化チャット（黒井）
- 住宅街の行き止まり・木の扉
- 六畳の空き部屋（切り抜き壁・台・ノート・石）

### 共通描写
1. 南京錠が「開いている」——誰かが待っている
2. ハンドルネームが先に書かれている
3. 深夜二時——スレが立つ／目が冴える時刻

### 第2話以降への伏線
- 黒井の「済」印（すでに次段階）
- 「第2回は、名簿の続きから」
- Secret: 案内人側への転落（シリーズ全体の裏ルート候補）

### 選択肢の注意
- 15字以内、価値観の差（慎重／大胆／傍観／受容）
- True は隠しにせず、本編の「受け入れる」で到達可能
- Secret は E01〜E05 回収後のみ
