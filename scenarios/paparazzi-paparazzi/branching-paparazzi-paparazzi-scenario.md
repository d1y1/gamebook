# 分岐型小説シナリオ：パパラッチ・パパラッチ

**版**: v1.0

---

## 0. この物語の法則（構成の芯）

練馬の雨上がりの夜、フリーのパパラッチが「名もなき君」を狙う。**レンズの向こうの男は情事現場ではなく、別れた女の写真を見て泣いているだけ**——その瞬間から、加害者と被害者の境界が揺らぐ。

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **撮るか、下ろすか** | シャッターを切る／カメラを下ろす | プライバシーと生計の天秤 |
| 第2分岐 | **写真をどうするか** | 編集部に送る／保留／消す | 正義と金の関係 |
| 第3分岐 | **結果にどう向き合うか** | 続ける／辞める／脅す | 業界との距離感 |

**走るモチーフ**:
- 望遠レンズ：無音の向こう側、安全な距離
- シャッター音：カシャ、という小さな暴力
- 名もなき君：本名不明の標的／やがて反転する視点
- 週刊誌の隅：三万円の値段、誰も覚えていない顔

**語り口**: 一人称・現在形。業界の内側を知るフリーカメラマン、自嘲と疲労。

## 1. 作品概要（100字以内）

**フック**: ゲスもゲス。安全なところから自分の正義を振りかざす。今夜のターゲットは名もなき君——練馬の六畳一間に、レンズを向ける夜。

**選択の意味**: 撮る／載せる／売る——それぞれが誰かの人生を値段に変える。Secretでは、レンズの向こうにもレンズがあった。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] シャッターを切る → S03-SHOOT
      ├─ [B] カメラを下ろす → S03-LOWER
      └─ [隠・2周目] 向こうの窓に、レンズがあった → S-SECRET-01 → S-SECRET-02 → E05
         │
S03-SHOOT ─┬─ [A] 編集部に送る → S04-SEND
           ├─ [B] 掲載を保留する → S04-HOLD
           └─ [C] データを消す → S04-DELETE
         │
S03-LOWER ─┬─ [A] 嘘のネタをでっち上げる → E03
           ├─ [B] 「撮れなかった」と報告 → S04-REPORT
           └─ [C] 黙って帰る → S04-LEAVE
         │
S04-SEND ─┬─ [A] このまま仕事を続ける → E02
          ├─ [B] 本人に接触して金を要求 → E03
          └─ [C] 掲載を止めさせる → S04-STOP
         │
S04-HOLD ─┬─ [A] 本人を脅して金を取る → E03
          ├─ [B] 掲載せずデータを消す → E01
          └─ [C] 編集部に送る → E02
         │
S04-DELETE ─┬─ [A] 辞表を出す → E01
            └─ [B] 言い訳して仕事に戻る → E04
         │
S04-REPORT ─┬─ [A] 続ける → E02
            └─ [B] カメラを売る → E04
         │
S04-LEAVE ─┬─ [A] カメラを箱にしまう → E01
           └─ [B] 結局、編集部に連絡する → E04
         │
S04-STOP ─┬─ [A] 辞表を出して引き下がる → E01
          └─ [B] 有名人側にリークして潰す → E03
         │
S-SECRET-02 ─┬─ [A] 握手を求める → E05
             ├─ [B] 黙って別れる → E02
             └─ [隠・全ED回収] この業界を暴く → E05（別バリエーション）
```
