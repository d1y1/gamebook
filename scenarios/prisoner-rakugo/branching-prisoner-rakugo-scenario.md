# 分岐型小説シナリオ：囚人落語

**版**: v1.0

---

## 0. この物語の法則（構成の芯）

罪を犯した若者が少年刑務所で落語に出会い、**「笑われる側」から「笑わせる側」へと一度だけ立場をひっくり返す**物語。選択によって、逃げる・半端に座る・本気で馬鹿になる・自分の罪を噺に変える、という異なる読後感に分かれる。

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **高座にどう向き合うか** | 古典をなぞる / 断って逃げる / 自分の話に変える | 恥を引き受ける覚悟 |
| 第2分岐 | **ヤジの中でどう続けるか** | 小さくまとめる / ヤケで続ける / 笑いまで持っていく | 自分を差し出す度合い |

**走るモチーフ**:
- 使い古しの落語本、味噌汁の染み、折れた背表紙
- 雑居房の湿気、点呼の足音、格子越しの視線
- ヤジと笑いの紙一重、喧嘩腰の声が喝采に変わる瞬間
- 出所後も越えられない「たった一度の高座」

**語り口**: 一人称・現在形に近い回想。乾いた口調の中に、若さと恥の熱を残す。

## 1. 作品概要（100字以内）

**フック**: 罪を犯した若者が、房の隅で拾った落語本を真似る。翌日、同室の先輩に「披露しろ」と言われ、ヤジだらけの雑居房で一席だけ座ることになる。

**選択の意味**: 笑われる前に逃げるか、半端にやるか、馬鹿になりきるか。恥をどう引き受けるかで、同じ高座の意味が変わる。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   ├─ [A] 古典をなぞる → S03-FORM
   │   ├─ [A1] 小さくまとめる → E02
   │   └─ [A2] ヤケで続ける → E01
   ├─ [B] 断って逃げる → S03-REFUSE
   │   ├─ [B1] 最後まで断る → E03
   │   └─ [B2] 一回だけ座る → E02
   └─ [隠] 自分の話にすり替える → S03-MIX
       ├─ [C1] 笑いまで持っていく → E04
       └─ [C2] 安全に畳む → E02
```

### 隠しルート（Secret: E04）

**解放条件**: E01 と E03 を回収済み

1. S02 に「自分の話にすり替える」が出現
2. 古典ではなく、自分の罪と見栄を噺の形に変えて話し始める
3. ヤジを押し返し、「笑いまで持っていく」を選ぶと E04

## 5. 執筆メモ

### 主要ロケーション

- 雑居房の棚と布団
- 洗濯場帰りの房内
- 格子越しに人が集まる即席の高座

### 共通描写（再利用可）

1. 点呼前後の足音や房の湿気
2. 格子越しに覗く囚人たちの顔
3. ヤジが笑いに変わる寸前の、息を止めたような間

### リプレイ設計

- E01 は依頼文の核となる王道ルート
- E03 は「逃げた場合」の痛みを明確に見せる短いルート
- E04 は落語の真似事を越え、自分自身を噺にする到達点
