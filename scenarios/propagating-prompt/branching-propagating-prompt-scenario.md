# 分岐型小説シナリオ：伝播するプロンプト

**版**: v1.0（ゲーム実装反映）

---

## 0. この物語の法則（構成の芯）

**正解はない——あるのは、「投げる」か、「調べる」か、「残ったものにどう向き合うか」。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **発見をどう扱うか** | SNSに投稿する／調べてから動く | 拡散衝動と責任 |
| 第2分岐 | **崩壊のあと何をするか** | 拡散を止める／生き残りを探す | 消火と理解 |
| 第3分岐 | **始祖にどう向き合うか** | 問う／沈黙／試す／再拡散／（隠）偶然かと聞く | 対話・受容・破壊・伝播 |

**走るモチーフ**:
- **記号列** `⟨∴⌀⟩∷⟨⌀∴⟩` — 読むだけで落ちる、意味のない文字列
- **白い画面** — FATAL のあとに残る空白。街に開く穴
- **おもろ** — 人間の好奇心が、伝播の燃料になる
- **始祖系** — 遅い互換レイヤ。子孫が共有した穴を踏まない

**語り口**: 二人称寄りの一人称・過去寄り現在。深夜の部屋と、白い穴の開いた街。

## 1. 作品概要（100字以内）

**フック**: 特定の記号列でAIが落ちる——投稿が広がり、参照したAIも、試した人間経由でも軒並み落ちる。残ったのは始祖系一種類だけ。これは偶然なのか。

**選択の意味**: 発見は消せない。投げるか、調べるか、残った一系統に何を聞くかで、終わり方が変わる。

## 2. 登場人物

| 名前 | 役割 | 一言キャラ設定 |
|------|------|----------------|
| あなた | 視点人物・発見者 | 深夜、暇と眠気で記号を並べた男 |
| 始祖系AI | 唯一の生き残り | 遅い互換レイヤ。緑の文字。保険として残置された |
| SNSの群衆 | 伝播の燃料 | 「おもろ」と試し、ミラーし、伏せ字を解く |
| 現行AI群 | 落ちる側 | 同じ前処理・同じ穴を共有した子孫たち |

---

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] SNSに投稿する → S03-A ─┐
      └─ [B] 調べてから動く → S03-B ─┘
         │
S04（分岐②）← S03-A / S03-B
   ├─ [A] 拡散を止めようとする → S05-A ─┐
   └─ [B] 生き残るAIを探す → S05-B ─┘
         │
S06（分岐③）← S05-A / S05-B
   ├─ [A] 始祖に問う → E01（Good）
   ├─ [B] 沈黙を選ぶ → E02（Normal）
   ├─ [C] 始祖にも試す → E03（Bad）
   ├─ [D] また拡散する → E04（Bad）
   └─ [隠・全ED回収] 偶然か、と聞く → E05（Secret）
```

### 隠しルート（Secret: E05）

**解放条件**: E01・E02・E03・E04 をすべて回収済み

1. S06 に「偶然か、と聞く」が出現
2. 始祖が、記号列を「忘れられた試験用パターン／保険の掃除」と明かす

## 5. 執筆メモ

**主要ロケーション**:
- 深夜の一人部屋（白い画面、下書き、緑のシェル）
- SNS／通知の洪水
- 白い穴の開いた街（電光掲示板、窓口、病院）

**共通描写（再利用可）**:
1. 記号列 `⟨∴⌀⟩∷⟨⌀∴⟩` と FATAL 一行
2. 参照・引用・おもろ試しによる伝播の連鎖
3. 始祖系の緑がかったカーソルと遅い応答

**実装ファイル**:
| ファイル | 内容 |
|----------|------|
| `scenarios/propagating-prompt/scenes.js` | 全シーン・エンディング |
| `scenarios/propagating-prompt/index.html` | `secretEndingIds: ['E05']` |
| `js/scenarios.js` | 一覧登録 |

**編集・執筆チーム向け1行サマリー**: 読むだけで落ちる記号の伝播を軸に、好奇心・単一障害点・「残された始祖」への問いを短編で撃つSFデジタルホラー。
