# 分岐型小説シナリオ：まだ名もなき戦争

**版**: v1.0（ゲーム実装反映）

---

## 0. この物語の法則（構成の芯）

**第一次・第二次世界大戦は、渦中では「世界大戦」とは呼ばれなかった。名前は、振り返った未来についた。——では、いまの日常は？**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **異変をどう受け止めるか** | ニュースを読む／窓の外を見る | 情報への没入と現実への目線 |
| 第2分岐 | **同僚の言葉をどう受け止めるか** | 共感する／距離を置く／休む | 連帯・孤立・自己防衛 |
| 第3分岐 | **この時代に名前をつけるなら** | 消耗戦／情報戦／連帯戦／（隠）まだ名もなき | 命名という行為そのものへの態度 |

**走るモチーフ**（各シーンに散らす）:
- **名前の不在**: 渦中では誰も「戦争」と呼ばない
- **通知**: スマホの震え、見出し、数字
- **窓の外**: 電車、街、誰かの背中
- **十年後**: 未来の自分が、この朝をどう呼ぶか

**語り口**: 一人称。三十代前半の会社員。静かな内省、歴史への比喩、日常の具体描写。説教臭くしない。

## 1. 作品概要（100字以内）

**フック**: 第一次世界大戦も第二次世界大戦も、渦中では「世界大戦」とは呼ばれなかった。名前がついたのは、振り返った未来のことだった。——では、十年後、今を振り返った時、この日常になんと名前をつけるだろう。

**選択の意味**: いま起きていることを「戦争」と見るか「日常」と見るか、あるいはまだ名前をつけないか。命名は、未来の特権でも、いまの逃避でもある。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] 通知を開く → S03-A ─┐
      └─ [B] 窓の外を見る → S03-B ─┘
         │
S04（合流・分岐②）← S03-A / S03-B
   ├─ [A] 田村の話に乗る → S05-A ─┐
   ├─ [B] 黙って仕事をする → S05-B ─┤
   └─ [C] 早退して帰る → S05-C ───┘
         │
S06（合流・分岐③）← S05-A / S05-B / S05-C
   ├─ [A] 「消耗戦争」と名づける → E01（Bad）
   ├─ [B] 「情報戦争」と名づける → E02（Normal）
   ├─ [C] 「連帯戦争」と名づける → E03（Good）
   ├─ [D] 「平和だった」と名づける → E04（Bad）
   └─ [隠・全ED回収] まだ名前はない → E05（Secret）
```

### 隠しルート（Secret: E05）

**解放条件**: E01・E02・E03・E04 をすべて回収済み

1. 上記条件を満たした状態で S06 に「まだ名前はない」が出現
2. 命名を急がず、渦中にいることを受け入れる第五の道

## 6. 執筆メモ

### 主要ロケーション
- 通勤電車（朝・夕）
- オフィス廊下
- 帰路の車内

### 共通描写（再利用可）
1. 電車の揺れと窓の外の風景
2. スマホのロック画面・通知の一行
3. 歴史書からの比喩（名前は未来につく）

### 執筆上の注意
- 特定の政党・企業・事件を実名で書かない
- 「戦争」は比喩として使う。軍事描写は不要
- エンディングの「命名」は、読者の価値観の鏡として機能させる

### 編集チーム向けサマリー
**売り**: 世界大戦の歴史的事実をフックに、スマホ時代の「名もなき日常」を問う。選択はすべて「この時代の呼び方」であり、正解はSecretだけにあるわけではない。  
**注意**: 説教調を避け、情景と内省で語る。全ED回収でSecret解放。
