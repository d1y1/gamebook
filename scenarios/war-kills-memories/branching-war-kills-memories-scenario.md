# 分岐型小説シナリオ：戦争は思い出を殺す

**版**: v1.0（ゲーム実装反映）

---

## 0. この物語の法則（構成の芯）

**戦争は人を殺すより先に、思い出を殺す。——語らないこと、閉じること、燃やすこと、一人で囲い込むことも、その続きになりうる。**

| 段階 | 問い | 例 | 読者に試されるもの |
|------|------|-----|-------------------|
| 第1分岐 | **封をどう扱うか** | 自分で開ける／祖母に聞く | 独断と共有、敬意と侵入 |
| 第2分岐 | **三つ何から触れるか** | フィルム／手紙／閉じ直す | 可視化・告白・不可知への態度 |
| 第3分岐 | **殺す側に立つか** | 語る／抱える／燃やす／封じる／（隠）探す | 記憶の倫理 |

**走るモチーフ**（各シーンに散らす）:
- **箱と紐**: 「開けないでくれたまえ」
- **三つ**: フィルム（闇）／名もない子供の写真／封書
- **茶碗**: 写真の子の小道具 → 春の茶 → 最後の「その子の分」
- **煙**: 焼いたアルバムの記憶、庭の焼却

**語り口**: 一人称「俺」。三十歳前後。静かな遺品整理。説教より余韻。特定の実在戦争に固定しない（架空の祖父の体験として）。

## 1. 作品概要（100字以内）

**フック**: 祖父は戦争の話を一度もしなかった。遺品の箱には「開けないでくれたまえ」——戦争は人を殺すより先に、思い出を殺す。

**選択の意味**: 遺された記憶を語るか、抱えるか、殺すか。開封そのものが暴力にも抵抗にもなりうる。

## 3. 分岐マップ（v1.0）

```
START
└─ S01（自動）→ S02
   └─ S02（分岐①）
      ├─ [A] 自分で封を切る → S03-OPEN ─┐
      └─ [B] 祖母に聞いてみる → S03-ASK ─┘
         │
S04（合流・分岐②）← S03-OPEN / S03-ASK
   ├─ [A] フィルムを現像する → S05-FILM ─┐
   ├─ [B] 封筒を開く → S05-LETTER ──────┤
   └─ [C] 箱を閉じ直す → S05-CLOSE ─────┘
         │
S06（合流・分岐③）← S05-*
   ├─ [A] 祖母にすべて話す → E01（Good）
   ├─ [B] 一人で抱え続ける → E02（Normal）
   ├─ [C] 箱を燃やす → E03（Bad）
   ├─ [D] 封じたままで終わる → E04（Bad）
   └─ [隠・全ED回収] 写真の子を探す → E05（Secret）
```

### 隠しルート（Secret: E05）

**解放条件**: E01・E02・E03・E04 をすべて回収済み

1. 上記条件を満たした状態で S06 に「写真の子を探す」が出現
2. 写真の手がかりから口述アーカイブへ辿り着き、殺されなかった笑顔と接続する

## 6. 執筆メモ

### 主要ロケーション
- 祖父の部屋（遺品）
- 縁側（春の茶）
- 写真屋
- 雨の夜の食卓／庭

### 共通描写（再利用可）
1. 紐で十字に縛られた箱と油性ペンの字
2. 茶碗（写真の子／春の茶／「その子の分」）
3. 「戦争は思い出を殺す」の反復（祖父の酔言→法則→読後）

### 執筆上の注意
- 特定の実在戦争・部隊・地名に固定しない（読者が重ねられる余白を残す）
- 祖父を単純な加害者／被害者にしない（命令・飴・罪と慈悲のあいだ）
- Secret は「正解ルート」ではなく、越境して記憶を接続する第五の道

### 編集チーム向けサマリー
**売り**: 遺品の箱をフックに、「記憶を殺す側に立つか」を問う戦争記憶もの。選択は開封・現像・焼却・共有など、手触りのある行為。  
**注意**: 実在の惨禍の再現ではなく、家族の沈黙と倫理の物語として書く。全ED回収でSecret解放。
